# InclusiveCode

InclusiveCode — ерекше білім беру қажеттіліктері бар оқушыларға Python тілін үш тәсілмен үйрететін интерактивті оқу платформасының демо нұсқасы.

## Техникалық құрылым

- Frontend: React, TypeScript, Vite, Lucide Icons, бейімделгіш CSS.
- Backend: FastAPI, SQLAlchemy, SQLite және JWT.
- Браузер симуляторы: Python-ның оқу мақсатындағы шектеулі бөлігі (`print`, айнымалы, `for range`, қарапайым `if`, тізім және қосу). Код серверде орындалмайды.
- AI көмекші: API кілтінсіз дайын қазақша жауаптар. Жауаптар backend-тегі `/api/assistant` арқылы беріледі.
- Демо прогресс браузердің localStorage қоймасында сақталады. Backend деректері SQLite базасына жазылады.

## Frontend-ті іске қосу

Node.js 20+ орнатып, жобаның түбірінде орындаңыз:

```bash
npm install
npm run dev
```

Vite көрсеткен мекенжайды браузерден ашыңыз. Production build жасау үшін `npm run build` пәрменін пайдаланыңыз.

## Backend-ті іске қосу

Python 3.10+ арқылы:

```bash
cd backend
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:INCLUSIVECODE_SECRET = "ұзын-кездейсоқ-құпия-кілт"
uvicorn app:app --reload --port 8000
```

API құжаттамасы: http://localhost:8000/docs. Негізгі жолдар: `/api/auth/register`, `/api/auth/token`, `/api/me`, `/api/lessons`, `/api/results`, `/api/progress`, `/api/accessibility`, `/api/tasks`, `/api/teacher/students`, `/api/teacher/tasks`, `/api/assistant`.

Тіркелгенде `role=teacher` мәні беріледі. Нақты пайдалануға шығарғанда мұғалім рөлін ашық тіркеуден алып, әкімші шақыруы арқылы беріңіз; JWT құпиясын ауыстырып, HTTPS және дерекқор сақтық көшірмесін қосыңыз.

## Симулятордың шектеуі

Бұл толық Python аудармашысы емес. Ол тек оқу мысалдарындағы қолдау көрсетілген құрылымдарды орындайды; қалғанына түсінікті қате көрсетеді. Пайдаланушы коды `eval`, `exec` немесе shell арқылы орындалмайды. Симуляторды қауіпсіз sandbox ретінде емес, рұқсат етілген шағын оқу мысалдарын тексеретін құрал ретінде қарастырыңыз.

## Оқуды бейімдеу ережесі

Келесі сабақ интерфейстегі тақырып ретіне сүйеніп ұсынылады. Backend-ке үш рет қатарынан 70 немесе одан жоғары ұпай келсе, келесі күрделілік «Күрделі» болады; 50-ден төмен ұпай болса «Жеңіл», басқа жағдайда «Орташа» ұсынылады. Нәтижелер `/api/results` және `/api/progress` арқылы сақталады.

## Басты мүмкіндіктер

- Қазақ тіліндегі сабақтар мен тапсырмалар, интерактивті редактор, кезеңдік орындау, шығыс пен айнымалы кестесі.
- «Көрнекі», «Қадамдап», «Өмірден» режимдері бір кодты сақтап, түсіндіру тәсілін өзгертеді.
- Браузерде прогресс пен жетістіктерді сақтау, мұғалім кабинеті, тақырып навигациясы.
- Қаріп өлшемі, қараңғы режим, контраст, ықшам интерфейс, браузердің мәтінді дыбыстауы, пернетақтамен басқару.
- SQLite API: JWT аутентификациясы, рөлдер, нәтиже/прогресс, қолжетімділік баптаулары, мұғалімнің тапсырма тағайындауы.

Мұғалім кабинетінде демоға арналған үлгі сандар көрсетіледі. Нақты оқушы деректерін `/api/teacher/students` API береді.
